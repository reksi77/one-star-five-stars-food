A one-sentence, one-star review of planet Earth written by an alien tourist — birds screaming at five in the morning, rain soaking a third set of tentacles — who would still come back for the grilled corn on the corner. Built for make.fun's "One Star, Five Stars for the Food" bounty.

## Run it

```sh
node main.ts
```

This writes the review (197 characters, one sentence, no trailing newline) to `/output/entry.txt`. The program checks its own output first: the review must be 1–200 ASCII characters, exactly one sentence ending in a single period, and the file on disk must match the review byte for byte.
